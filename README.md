## Учебные проекты

### Stroke Segmentation

Проект, посвященный задаче сегментации очагов ишемического поражения на МР-снимках головного мозга.

Датасет: ISLES 2022

Что реализовано:
* Подготовка и предобработка МР-изображений
* Обучение и сравнение моделей глубокого обучения для 3D-сегментации: 3D U-Net, 3D Attention U-Net, 3D U-Net++, Swin UNETR
* Доработка лучшей модели
* Формирование ансамбля моделей сегментации очагов разного размера.

Результат: Разработана модель, показывающая:
* на уровне пациента: F1 равный 0.94, коэффициент Спирмена - 0.96, Dice - 0.64
* Для отдельных очагов: Dice крупных очагов - 0.66, Dice мелких очагов - 0.36

Стек: PyTorch, MONAI, NumPy, Pandas, SimpleITK, SciPy, MedPy, NiBabel, Nilearn, Matplotlib, Seaborn

### Blood Cells Detection

Проект, посвященный задаче детекции и классификации клеток крови на микроснимках мазков крови

Датасет: BCCD

Что реализовано:
* Подготовка изображений и аннотаций
* Аугментация изображений
* Обучение 4 архитектур детекции объектов: SSD300, Faster R-CNN, RetinaNet, FCOS
* Оценка качества детекции с использованием mAP.

Результат: Разработана модель, показывающая mAP@50 равный 0.754 и mAP@75 - 0.663

Стек: PyTorch, torchvision, torchmetrics, Albumentations, OpenCV, XML.etree.ElementTree

### Philosophical Assistant

Проект, посвященный разработке локальной RAG-системы для поиска и генерации ответов по философским текстам.

Датасет: SEP, тексты философских произведений от Project Gutenberg

Что реализовано:
* Создание корпуса философских текстов
* Получение текстовых эмбеддингов с использованием Sentence Transformers
* Семантический поиск по векторному индексу FAISS
* Генерация ответов локальной LLM через Ollama
* Разработка пользовательского интерфейса на Streamlit
* Поддержка генерации ответа на языке запроса

Стек: Requests, Pandas, Numpy, Sentence Transformers, FAISS, Ollama, Qwen, Streamlit

### Anime Recommendation System

Проект, посвященный построению рекомендательной системы на основе пользовательских оценок и характеристик аниме тайтлов.

Датасет: Anime Recommendations Database

Реализованные подходы:
* Базовая система рекомендаций на основе популярности
* Контентно-ориентированная система на основе признаков тайтлов
* Система коллаборативной фильтрации на основе SVD
* Гибридная система, объединяющая контентный и коллаборативный подходы

Результат: для используемого датасета наиболее эффективным оказался подход на основе рекомендации популярных непросмотренных пользователем тайтлов.

Стек: Pandas, NumPy, Scikit-learn, Surprise, Matplotlib, Seaborn

### Brain Disease Classification

Проект, посвященный задаче классификации окрашенных КТ-изображений с использованием методов Computer Vision.

Датасет: Brain CT Medical Imaging Colorized Dataset

Что реализовано:
* Подготовка и аугментация изображений
* Обучение и сравнение нескольких архитектур: ResNet 18, VGG 16, EfficientNet_B0
* Анализ ошибок и особенностей датасета
* Использование Grad-CAM для интерпретации предсказаний моделей

Результат: проведено сравнение архитектур и выявлены особенности датасета, ограничивающие оценку практической применимости полученных моделей

Стек: PyTorch, Albumentations, torchvision, Matplotlib, GradCAM
